## Назначение

Этот документ — накопительный слой для будущего единого файла Mind Map CoBook.
Он не заменяет и не переписывает `COBOOK_PRE_MINDMAP.md`. В него последовательно сводятся подтверждённые результаты разбора веток.

Правило: не переносить будущую реализацию в текущий кодовый аудит. Фиксировать только то, что уже обсуждено/проверено, отдельно отмечая реальные ошибки и то, что пока не реализовано.

# График

## Зафиксированные архитектурные правила

- Общий UI/CSS является единым визуальным слоем.
- Не допускаются самовольные отдельные CSS-системы внутри отдельных веток.
- Если UI-компонент используется только одной веткой, это не означает, что его визуальная реализация должна дублироваться в этой ветке: общий UI-компонент остаётся общим, а принадлежность использования определяется веткой.
- Календарная сетка — один общий UI-компонент.
- Переключатель `Год → Месяц → День` — отдельный общий UI-компонент, используемый Графиком.
- Переключатель `Месяц → Год` — отдельный общий UI-компонент, используемый Журналом.
- Состояние и результат использования этих компонентов не являются общими: График и Журнал могут находиться на разных месяцах.
- Если в Графике календарная сетка или её состояние ошибочно связаны как единое состояние с другой веткой, это является ошибкой.
- Дополнительные настройки, относящиеся только к Графику, остаются принадлежностью Графика; их не следует превращать в глобальные настройки.

## UI

- Календарная сетка — общий UI.
- Управление рабочим периодом и формирование рабочего дня — ответственность Графика.
- Отображение рабочего дня в сетке — по состоянию, сформированному Графиком.
- Временной блок рабочего дня — специальное содержание Графика, использующее общий UI.
- Общие выпадающие/модальные элементы не дублируются внутри Графика.

## CSS

- Главный принцип: единый общий CSS.
- Специфические классы допустимы только как контекстные варианты общего визуального слоя, а не как отдельная визуальная система.

# Журнал

## Архитектура

```text
Журнал
├── День
├── Месяц
└── Список
```

Журнал — главная ветка для сущности `Запись`.
Сущность `Запись` в текущем коде ещё не реализована.

Рабочие дни и рабочее время поступают из Графика. Журнал отображает их, не забирая у Графика владение рабочим днём.

### Важное правило владения

- Рабочий день принадлежит Графику.
- Журнал может отправить Графику запрос на изменение рабочего состояния дня.
- Решение и сохранение рабочего дня остаются ответственностью Графика.
- Будущая сущность `Запись` принадлежит ключевой ветке Журнал, а не дочерним представлениям День/Месяц/Список.

---

# Журнал → День

## Текущий UI

- Поле дня отображается корректно.
- Используется общий UI.
- Переключатель `День → Месяц → Год` используется в этом представлении.
- Состояние рабочего/выходного дня приходит из Графика.
- Если день рабочий, отображается рабочее поле.
- Если день выходной, отображается пустое поле с плашкой «Выходной день».

## Действия

- Нажатие на плашку выходного дня должно вызывать существующий общий UI-процесс для запроса Графику сделать день рабочим.
- Этот вызов в текущем коде пропал и должен быть восстановлен.
- Сам UI процесса не должен создаваться заново внутри Дня: используется общий UI.
- Запись клиента сейчас не рассматривается.
- Нижние дополнительные кнопки пока не рассматриваются.

## Статус

- 🟢 Отрисовка Дня — корректна.
- 🟢 Переключение представления — работает.
- 🔴 Вызов процесса «сделать выходной день рабочим» через плашку отсутствует.
- ⏸️ Сущность `Запись` ещё не реализована.

# Журнал → Месяц

## UI

- Используется общая календарная сетка.
- Используется отдельный общий переключатель `Месяц → Год`.
- Переключатель и календарная сетка — разные общие UI-компоненты, связанные внутри конкретного представления.
- Состояние месяца Журнала независимо от состояния Графика.
- График может находиться, например, в январе, а Журнал — в сентябре.
- В Журнале отображается только месяц; режим Дня здесь не является частью этого представления.

## Отображение

- Показываются рабочие и выходные дни согласно состоянию, сформированному Графиком.
- Дополнительные данные будущей `Записи` пока не добавляются.

## Навигация

- Цифра даты кликабельна.
- Нажатие на дату переводит в `Журнал → День` выбранной даты.
- Этот переход в текущем коде работает.

## Статус

- 🟢 Календарь отображается.
- 🟢 Переключатель `Месяц → Год` работает.
- 🟢 Клик по дате → День работает.
- 🟢 Рабочие/выходные состояния отображаются по данным Графика.
- ⏸️ Счётчики и дополнительные показатели пока не создаются.
