# CoBook — PROJECT STATE

## Источник истины

`main` — текущая рабочая и контрольная точка проекта.

## ОБЯЗАТЕЛЬНЫЙ ПРОТОКОЛ НАЧАЛА КАЖДОЙ РАБОЧЕЙ ЗАДАЧИ

Перед выполнением **каждой рабочей задачи** ChatGPT обязан заново прочитать актуальный `PROJECT_STATE.md` из `main` и использовать его как обязательный источник правил для этой задачи.

Рабочей задачей считается любое обращение пользователя, которое требует изменения, исправления, проверки, реализации, рефакторинга, публикации или иного действия над проектом, включая `теперь работаем`, `сделай`, `добавь`, `исправь`, `проверь`, `реализуй` и аналогичные формулировки.

Исключение: если пользователь явно переводит разговор в режим обсуждения (`давай обсудим`, `теперь вопрос`, `давай поговорим`, обсуждение архитектуры без просьбы о реализации), чтение `PROJECT_STATE.md` перед ответом не требуется. Как только обсуждение переходит в реализацию — `PROJECT_STATE.md` снова читается до начала работы.

После чтения документа обязательны: проверить существующую архитектуру, реализовать внутри владельца MODULE, проверить отсутствие дубликатов, проверить затронутые сценарии, проверить отсутствие регрессий, проверить публикацию для того же commit SHA и фактическую опубликованную версию. Только после полного успешного протокола разрешены commit и ссылка.
