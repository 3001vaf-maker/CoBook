# CoBook — Online Booking

Самостоятельный прототип Mini App для онлайн-записи мастера.

## Что уже работает

- режим мастера и режим клиента;
- услуги с ценой и длительностью;
- рабочие дни и часы;
- перерывы;
- исключения по конкретным датам;
- шаг записи;
- расчёт свободных слотов из расписания, перерывов, исключений и существующих записей;
- повторная проверка слота перед созданием записи;
- календарь мастера;
- создание тестовой записи;
- данные сохраняются в браузере через localStorage;
- демонстрационный человек подключён только по `personId`, полноценной базы клиентов внутри CoBook нет.

## Тестовые данные

Прототип уже заполнен услугами парикмахера, рабочим графиком и двумя демонстрационными записями. Их можно изменить через интерфейс.

## Важно

Сейчас это автономный прототип пользовательской логики. Telegram WebApp API, настоящий backend, база данных и интеграция с внешней системой людей намеренно не подключены. Они будут следующим слоем после проверки интерфейса и логики.

## Запуск

Открой `index.html` через любой статический веб-сервер. Для GitHub Pages достаточно включить публикацию из ветки `main`.
